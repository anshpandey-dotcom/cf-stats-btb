# PING AI Privacy Policy

PING AI is an auto-reply assistant. It reads incoming chat notifications on your device only to write and send a reply for you.

- Message text is sent to Google's Gemini API using the API key you provide, only to generate a reply. Google's own terms apply to that request.
- Your API key, name, custom replies, contact lists and activity log are stored only on your device. The app has no server and no analytics, and it does not sell or share data.
- The app does not read SMS, contacts, call logs or accessibility data.
- Notification access can be revoked at any time in Android settings, and uninstalling the app removes all stored data.
